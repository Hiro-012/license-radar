license-radar

Dependency license compliance scanner for Python and Node projects.

license-radar statically scans a project's dependency manifests — requirements.txt, pyproject.toml, setup.cfg, Pipfile, package.json, including monorepo subprojects — for GPL/AGPL and other copyleft license risk, before an accidental dependency turns into an obligation to open your own source or a legal problem for a closed-source product.

Install

pip install license-radar
license-radar scan .

Free vs. Pro

FreeFull directory/monorepo scan, every manifest format, --online lookups, --json, custom --policy, and a pre-commit hook. No telemetry, no key required.
Pro — one-time purchaselicense-radar report: a standalone HTML compliance audit report (per-dependency table, risk-tier summary, applied policy, audit scope) suitable for archiving or handing to legal/compliance review.
